# Android vs Unity controlled comparison

Android baseline: AEP Android v0.5.3 (frozen).
Unity iteration: v0.1.0.

Track per iteration:
1. setup/build effort,
2. number of iteration cycles,
3. visual/gameplay quality,
4. pose/live latency,
5. startup/session stability,
6. CPU/GPU/memory/package footprint,
7. renderer-specific code volume,
8. licensing/runtime implications.

Do not change the locked Rock Dodge behavior merely to make the Unity renderer easier.
